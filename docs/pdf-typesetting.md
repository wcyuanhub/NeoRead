# PDF 保留排版译文

保留排版模式使用 BabelDOC 0.6.4 重新生成译文 PDF，再由现有 PDF.js 显示。阅读和「导出译文 PDF」使用同一份生成文件。连续文本模式保留原有逐句阅读和批注能力。

## 数据路径

1. Go 从当前解析清单与已保存译文建立快照，只包含状态为 complete、原文哈希一致的译文；图片和表格只使用已翻译图注，不把整张图的标签当作正文。重新翻译时可以继续使用已有的有效译文。
2. BabelDOC 独立子进程解析原 PDF，生成布局、段落、公式和样式的中间表示。适配层按页、几何位置及文本相似度，对应已保存段落或连续完整句子的译文，不调用模型或在线翻译服务。
3. BabelDOC 排版并生成单语译文 PDF。不能可靠对应的段落保留原文。公式只有在符号对应通过校验后才复用原 PDF 的向量内容；引用编号、脚注和重音符单独处理。
4. 子进程正常退出、完成协议与文件验证通过、快照仍为当前版本后，Go 原子发布 PDF 和统计。PDF.js 使用现有带 capability 的资源地址加载，支持分页懒加载、缩放、主题及按页视口同步。

快照摘要包含适配版本、解析清单和有效译文。更改译文或解析结果后自动生成新版本，不提供过时版本的资源。生成期间不覆盖已保存译文、不推进学习或翻译阶段。

`GET /api/documents/{id}/translations/typeset` 查询状态，`POST` 创建或复用任务，均使用现有本地鉴权。状态包含等待译文、组件不可用、执行阶段、完成和受控失败原因。

## 开发与打包

需安装 [uv](https://docs.astral.sh/uv/)。第一次准备运行时需要联网下载 Python、依赖、字体和布局模型：

```sh
pnpm prepare:babeldoc
pnpm dev
```

准备脚本在 `.runtime/babeldoc/` 创建 portable Python 3.12.11、带哈希的锁定依赖、离线资产及 `worker.py`。开发脚本和桌面主进程通过 `NEOREAD_BABELDOC` 指向此目录；独立 Go 服务需显式设置这个环境变量为绝对路径。缺少运行时会显示组件不可用和重试入口。

`pnpm package` 在打包前准备运行时并将它复制到 `resources/babeldoc`。只在原生目标平台准备运行时，不在一台机器上交叉复制 Python/ONNX 二进制。当前 macOS ARM64 运行时约 1 GB，安装包体积会增加；本次只验证此平台的实际排版，未验证 Windows、Intel Mac 安装包及签名。

依赖固定在 `scripts/babeldoc/requirements.lock`。更新依赖时重新编译锁文件，并检查两个缓存路径补丁和固定版本的段落钩子；不能只放宽版本号。资源在准备阶段下载，任务阶段禁止 socket 连接；资源缺失时失败，不转为在线下载。

## 生命周期与恢复

生成任务注册到现有文档任务生命周期，删除文档、重新解析和关闭服务会取消并等待任务结束。全局一次运行一个排版子进程，单次上限 30 分钟。临时快照、中间表示及 BabelDOC 翻译缓存只在私有 `.pending-*` 目录中存在，成功/失败后清理；进程崩溃遗留目录在该文档下次生成时清理。

最终缓存位于 `<library>/cache/<documentId>/typeset/<revision>/`，只保留 `translation.pdf` 和 `result.json`。新版本成功发布后清理旧版本。取消导出仅终止前端轮询和下载，不取消其他阅读视图正在共享的生成任务。

## 第一版限制与人工验收

- 不同解析器拆分段落不完全一致。跨块合并、缺句、公式结构或顺序不可靠时保留英文，不会把整段译文硬塞进小片段。参考文献、图中标签和未翻译区域通常保留原文。译文完整内容仍可在连续文本阅读。
- 生成 PDF 的文字支持复制。尚未建立重排后文字到 NeoRead 原句的精确映射，因此保留排版视图暂不提供逐句批注和精确句子跳转；这些功能在连续文本模式使用。并排同步按页与视口，不能保证逐行对齐。
- 只验证了两篇实际论文，不代表所有扫描件、旋转页、复杂表格及字体都能正确重排。不改变原 PDF 页数与纸张尺寸。

人工检查：打开已有完成译文的 PDF，切换「保留排版」，等待生成；检查中文正文直接显示、图表及公式无明显重叠、翻页与深浅主题可用。再导出译文 PDF，确认与阅读内容一致。切换连续文本检查逐句批注。修改译文后回到保留排版，确认重新生成；删除或重新解析时确认没有残留生成任务。

自动检查：`pnpm typecheck`、`pnpm test`、`pnpm build`。Python 适配边界测试使用准备好的 Python，并将 `PYTHONPATH` 指向 `.runtime/babeldoc/site`，执行 `python -m unittest discover -s scripts/babeldoc -p test_worker.py`。

## 第三方许可证

BabelDOC 使用 AGPL-3.0，PyMuPDF/MuPDF 也涉及 AGPL。适配层、缓存位置修改、上游地址及许可证位置见 [修改与授权说明](../scripts/babeldoc/NOTICE.md)。准备脚本保留上游 Python 源码、许可证和 NeoRead 适配源码。正式分发前需确认整体分发方式与对应源码提供方式符合相关许可证；本次没有制作公开发行包。
